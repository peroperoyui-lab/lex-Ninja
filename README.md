# 蕾忍宗 · 宗门大比

**非官方二创 / 本地双人 / AI 对战 / 忍术原声**

零运行依赖的 HTML + Canvas + Web Audio 格斗原型。打开 `index.html`，点击「导入忍术.zip」选择本地音源，再点击「开始切磋」。也可以不导入音频，进行无语音练习。无需 Node、服务器、API、账号或外部素材站。桌面键盘版；尚未制作触屏按键。

## 已实现

- 原创程序绘制的经典黄脸黑头套半身忍者、独立黄色手部与刀具动作；不添加腿或完整人体。
- P1 / P2 独立选择玩家或 AI，支持玩家对战、玩家对 AI、AI 对 AI；P2 可选训练木桩。
- 60 Hz 固定战斗逻辑、移动、跳跃、下蹲、防御、轻重击、8 个有对应音源的忍术。
- 前摇 / 生效 / 后摇、能量消耗、冷却、受击硬直、命中停顿、往返飞行物、短暂无敌、护盾及格挡穿透投技。
- 相对朝向搓招、约 433 ms 方向记忆、约 67 ms 组合键容错、10 帧动作缓冲；最多三个同时按键。
- 逐角色语音通道、音量控制、本地 ZIP / 音频导入、原声检索试听；没有声音时不冒充播放成功。
- 失焦自动暂停、清空按键、F2 判定框、减少震动选项、一局 99 秒、胜负与重开。

## 按键

| 动作 | P1 | P2 |
|---|---|---|
| 左右 / 跳 / 蹲 | A D / W / S | ← → / ↑ / ↓ |
| 轻击 / 重击 / 防御 | J / K / L | Num1 / Num2 / Num3 |
| 十字斩 / 悠悠球 / 闪现快捷键 | U / I / O | Num4 / Num5 / Num6 |
| 暂停 / 重开 / 判定框 | Esc / R / F2 | 共用 |

方向为**相对朝向**，↓→ 表示先下后前；换边以后「前」也随之改变。

| 忍术 | 搓招 | 前摇 / 生效 / 后摇（帧） | 能量 |
|---|---|---|---|
| 影分身十字斩 | ↓ → 轻，或 U / Num4 | 13 / 12 / 23 | 24 |
| 一刀一刀燃烧刀 | ↓ → 重 | 18 / 24 / 30 | 32 |
| 纳米悠悠球 | ↓ ← 轻，或 I / Num5 | 16 / 1 / 24 | 20 |
| 哎呦卧槽闪现 | ↓ ← 重，或 O / Num6 | 7 / 1 / 15 | 22 |
| 岩石耐击术 | ↓ + 防 | 9 / 1 / 21 | 24 |
| 奥义升龙 | → ↓ 重 | 11 / 17 / 31 | 35 |
| 死神的手 | 轻 + 重 | 10 / 5 / 26 | 18 |
| 黑龙武神 | 轻 + 重 + 防 | 42 / 18 / 46 | 90 |

「生效 1 帧」表示在该帧生成飞行物 / 触发效果，不代表飞行物或护盾只持续 1 帧。数值是首轮试验参数，不是社区公认设定或已经完成的平衡结果。

普通攻击延迟 4 帧判定组合键。跨键盘双人多键输入仍受键盘硬件键位冲突限制，软件无法保证所有键盘都无冲突。数字小键盘使用 `KeyboardEvent.code` 区分顶部数字。

## 音频与单文件打包

源码仓库不内置第三方原声。导入只读取你明确选择的文件，不上传。浏览器导入支持非加密 ZIP（store / deflate，GB18030 / UTF-8 名称），不支持 ZIP64；不支持解压的浏览器可先解压再多选 WAV。关闭 / 刷新页面后需重新导入。

使用 Python 3 制作内置全部原声的离线单文件：

```sh
python scripts/build_portable.py --audio-zip "忍术.zip"
```

然后打开 `dist/lexburner-play.html`。没有 `--audio-zip` 则生成可自行导入声音的单文件。原音未变速、未重配音、未用合成声音冒充。音频文件名必须与招式名一致；开场名为「吓我一跳我释放忍术」。

用户素材包盘点为 81 个 WAV。首发只采用实有音源，不包括包中没有的「哈姆杀所有」「岚刀一直切」「握握双手」等后期招式。

## 开发与测试

- `src/combat.js`：纯逻辑战斗、指令、AI，可在 Node 下测试。
- `src/audio.js`：Web Audio、本地 ZIP 解压及音源管理。
- `src/game.js`：程序绘图、界面、固定步长循环。
- `tests/combat.test.cjs`：规则测试；`node --test tests/*.test.cjs`。
- `scripts/build_portable.py`：无依赖离线打包及 SHA-256 音源索引。

本版不用 Phaser / Vite，以便直接从文件打开及导出无依赖 HTML；后续可在不改变纯战斗逻辑接口的前提下替换渲染器。不包含在线联机、回滚网络、完整动画骨骼、手机触屏控制或经过充分实测的竞技平衡。

## GitHub Pages

在仓库 Settings → Pages 选择 Deploy from a branch，分支选择放有 `index.html` 的分支、目录 `/ (root)`。本站没有后端；页面上的原声导入也只在访问者浏览器内进行。仓库内有 `.nojekyll`，所有资源使用相对路径。Pages 是否启用以仓库实际设置为准。
