# 蕾忍宗 · 宗门大比

**非官方二创 / 本地双人 / AI 对战 / 忍术原声**

「蕾忍」梗的二创格斗小游戏。HTML + Canvas + Web Audio，零运行依赖，无需 Node、服务器、账号或联网。桌面键盘版；尚无触屏按键。

当前版本：**v0.6 + 招式光效层**。

## 快速开始

1. 用 Chrome / Edge 等桌面浏览器打开根目录的 `index.html`（单文件，双击即可）。
2. 点「开始对决」，选择两个席位各是玩家还是 AI，再开战。
3. 第一次玩可先点「新手修炼」，里面有逐步教学与单招练习。

> 在 Claude 应用等带预览窗口的环境里，`index.html` 约 2.5 MB，预览可能被截断导致按钮失效；请下载后用浏览器打开。

## 已实现

- 两个独立席位：玩家或 AI。P1 可选玩家 / AI；P2 可选 AI / 玩家 / 训练木桩。
- 60 Hz 固定步长战斗逻辑；前摇 / 生效 / 后摇、能量、冷却、受击硬直、命中停顿；AI 与玩家使用同一套规则。
- 3 个普通攻击 + 26 个技能，共 29 个动作；每个技能都有对应原声。
- 三格怒气（上限 300）：黑龙武神耗 3 格，豪兽雷鸣耗 2 格，黑暗紊乱升龙和舍利子回魂各耗 1 格。
- 二段跳、冲刺（冷却约 1.3 秒）、两座可攀爬的神社平台、双人共用镜头，场地宽 3200。
- 连续受控累积僵直，满条自动脱身并获得约 2 秒免控；锁定类技能共用 6 秒冷却，且只能标记前方范围内的对手。
- 内嵌 BGM 播放器与「原声大碟」（81 段原声可检索试听），音量、静音、减少闪光与震动可在设置里调整。
- 窗口失焦自动暂停并清空按键；按 F2 显示判定框。
- 招式光效层（v0.6 新增，仅渲染）：见下文。

## 按键

使用物理键位（`KeyboardEvent.code`），最多同时三键。方向为**相对朝向**：「→」是朝向对手的方向，换边后随之翻转。

| 动作 | P1 | P2 |
|---|---|---|
| 左右 / 跳 / 蹲 | A D / W / S | ← → / ↑ / ↓ |
| 备用跳 / 冲刺 | Space / 左 Shift | 小键盘 0 / 小键盘 . |
| 轻击 / 重击 / 防御 | J / K / L | 小键盘 1 / 2 / 3 |
| 快捷技 U / I / O | U / I / O | 小键盘 4 / 5 / 6 |
| 暂停 | Esc | 共用 |

## 招式光效层

`index.html` 的渲染模块在原有美术切图光效之上，追加了一层只负责画面的光效（`Renderer.more` / `projMore` / `fxEvent` / `fxDraw` / `vignette`），不读写战斗状态：

- 近战：拔刀弧光与居合线、十字斩 X 斩、燃烧刀地面热浪与火星、升龙螺旋光柱、旋风螺旋、死神之手与夺心的心形、闪现斩的交叉刀痕。
- 远程与法术：悠悠球牵线与残影、火球火焰尾迹、飞矢彗尾、豌豆与水浪拖尾、梦球 Z 字、雷霆地面闪光与分叉、陨星冲击波、冰霜雪片。
- 防守与身法：岩石耐击术的旋转石片、烟雾漩涡、回魂光点、疾行光环、闪现的双漩涡与轨迹线。
- 奥义：黑龙武神发动时的暗角与放射线、枪口光晕和地面光带。
- 命中反馈：星爆、刀痕、碎片；防御时为六角火花；重击额外加冲击环。

勾选「减少闪光与震动」后，震动与全屏闪光会关闭，阴影发光也会降低。

## 音频与版权

- `index.html` 内嵌了你提供的 81 段原声和一首 BGM「蕾忍摇【二补】」（约 47.4 秒）。这些第三方素材不属于本仓库的 MIT 许可，版权归原权利人，见 `LICENSE` 末段。
- 原声按**文件名**匹配招式名；26 个技能的名称与开场语音「吓我一跳我释放忍术」都已核对到确切的文件名。没有核对过的语音不会被当作存在。
- 约定：不对原声变速或重配音，也不用合成声音冒充原声；命中、落地等音效是浏览器内合成的提示音。
- 「原声大碟」支持再导入自己的 ZIP / WAV / MP3，导入只在本机读取，不上传。

## 仓库结构

- `index.html`：**当前可玩的 v0.6 单文件构建**，渲染、战斗、音频、舞台、界面模块与素材都在其中。
- `src/`、`tests/`、`scripts/`：更早的 v0.1 原型模块、对应测试与旧版打包脚本。`index.html` 不加载 `src/`；`scripts/build_portable.py` 针对 v0.1 的文件布局，**不能**用来构建 v0.6。
- v0.6 的分模块源码和构建脚本不在本仓库中；目前以 `index.html` 为唯一来源。
