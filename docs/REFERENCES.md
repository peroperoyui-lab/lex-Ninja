# 演出参考与取舍

用户目标：保留蕾忍二创的半身黄脸忍者，让招式像格斗游戏而不是音效播放器。参考《死神 VS 火影》的出招节奏、命中反馈、连段和能量管理，不复制角色、特效图集、源码或配乐。

## 已核对的参考

- 4399《死神VS火影3.3》发布页：https://www.4399.com/flash/205551.htm
- 原项目：https://github.com/5DPLAY-Game-Studio/BleachVsNaruto
- 二创截图及梗交互背景：https://www.3dmgame.com/original/3745318.html
- 实际查看的忍者截图：https://img.3dmgame.com/uploads/images/news/20250421/1745241516_989427.png

参考截图的识别要点是圆大眼睛、厚黑头套、遮住下半脸的面罩、黄色眼部与独立黄手。v0.2 用 Canvas 自绘这些形体，保留半身漂浮，没有添加完整人体或腿。

## 后续重点

在更多实机反馈后调整眼型、手势、距离、打击音色、受击方向和能量获取速度。需要精确贴近某一二创时，应提供可直接查看的片段，先对动作和音频时间点做标注，再调整动画事件，不凭梗名猜演出。
